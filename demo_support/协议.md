# 合作方门户

python portal/server.py --port 8787 启动后访问回环地址。演练账号由按钮创建，无真实凭据。机构选择会异步刷新期间和口径，服务端筛选状态属于当前会话；生成导出时冻结筛选信息，后续切换不改变旧导出。旧导出保留在下载列表，CSV 自身带 export_id、org、period、metric、record_id、amount。

演练服务内部端点只用于驱动网页和检查来源，不是业务方承诺的下载 API；产品采集流程通过页面操作。服务端 /export 的 delay 参数控制晚到，/expire 令当前会话失效。独立浏览器上下文不能读取另一会话的导出。DataHarbor 的正式数据 schema 可包含这些来源字段，映射与权限由原模块配置。
